# Roland Garros Inspired Design Direction

This direction is inspired by clay-court tennis color language: red clay, deep green, ivory, and deep blue. It does not copy the Roland-Garros logo or official tournament marks.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Clay | `#B86A3A` | Primary CTA, score highlights, active states |
| Burnt Clay | `#8F4B2E` | Hover states, chart depth, badges |
| Deep Court Green | `#06492D` | App shell, nav, premium brand anchor |
| Court Green | `#0F6B43` | Positive status, selected chips |
| Ivory | `#F5EBDD` | Main text on dark surfaces, report paper feel |
| Chalk White | `#FFF8EF` | High-emphasis text |
| Night Navy | `#0B1820` | Background and contrast base |
| Graphite Green | `#10231D` | Panels and cards |
| Gold Sand | `#D9A45F` | Secondary accent, roadmap, warnings |

## UI Personality

- Premium clay-court performance lab.
- More elegant and tactile than neon sports-tech.
- Still fast, athletic, and coach-focused.
- Arabic/English bilingual by default.
- Language toggle must be a first-class control in the top bar.

## Core Screens

1. Dashboard / لوحة التحكم
2. Evaluation / التقييم
3. Report / التقرير

## Navigation

Mobile bottom navigation:

- Dashboard / الرئيسية
- Players / اللاعبون
- Evaluate / التقييم
- Reports / التقارير

Desktop sidebar keeps the same items with the logo lockup at the top.

## Buttons

- Primary: Clay background, ivory text.
- Secondary: Deep green panel, ivory border.
- Utility: Ivory icon button on green/graphite surface.
- Language: segmented pill `EN | عربي`, visible in the app bar.

## Logo Direction

Custom mark: padel racket + court lines + performance signal. Avoid official Roland-Garros monograms, tennis federation marks, or copied tournament identity.

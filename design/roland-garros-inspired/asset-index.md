# Roland Garros Inspired Design Assets

Saved inside the project:

1. `01-logo-system.png`
   - Custom logo direction.
   - Includes app icon, English lockup, and Arabic lockup.

2. `02-dashboard-mobile.png`
   - Mobile dashboard concept.
   - Includes bilingual language toggle, top bar, bottom navigation, CTA, stats, recent evaluations, and search.

3. `03-evaluation-mobile.png`
   - Mobile live evaluation concept.
   - Includes bilingual controls, category accordions, sliders, note chips, and sticky save/generate actions.

4. `04-report-mobile.png`
   - Mobile player report concept.
   - Includes bilingual report hierarchy, score, level, playing style, radar chart, PDF export, roadmap, and development areas.

## Public Paths

`public/design/roland-garros-inspired/`

## Design Decision

The visual system uses a clay-court inspired palette:

- Clay: `#B86A3A`
- Burnt Clay: `#8F4B2E`
- Deep Court Green: `#06492D`
- Court Green: `#0F6B43`
- Ivory: `#F5EBDD`
- Night Navy: `#0B1820`
- Gold Sand: `#D9A45F`

The app should remain a custom Coach Faisal padel brand, not a Roland-Garros clone.

## Visual Language

- Cinematic dark sports-tech interface.
- Telemetry grid background with subtle scanline overlay.
- Glass panels with tactical borders and glow.
- Amber/clay action and score highlights.
- Cyan/green intelligence accents.
- High-contrast mobile-first hierarchy.
- Formula 1 telemetry x elite athlete lab mood.

## Interaction Polish

- Cards lift on hover.
- CTAs use glow and shimmer treatment.
- Accordions reveal with motion.
- Sliders use tactical amber glow.
- Active navigation uses premium glass/ivory state.
- Report charts use dark radial chart wells.
